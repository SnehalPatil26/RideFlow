About RideFlow

RideFlow is a Smart Ride Data Engineering and Analytics Platform designed to demonstrate an end-to-end data pipeline using real ride-booking data.


The system performs data ingestion, cleaning, validation, transformation and storage before exposing analytics through a Flask API and interactive dashboard.
